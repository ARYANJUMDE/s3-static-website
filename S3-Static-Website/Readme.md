# AWS S3 Static Website Hosting

## Project Overview
This project demonstrates hosting a static website using Amazon S3.

## Technologies Used
- AWS S3
- HTML

## Steps Followed
1. Created S3 bucket
2. Uploaded index.html
3. Enabled static website hosting
4. Disabled block public access
5. Added bucket policy for public access
